# 요구사항 정의서

> 프로젝트 이름: 부끄(Bookku)
> 도서만을 위한 공간을 찾는 독서인들의 공간

---

## 1. 프로젝트 개요

### 1.1 배경 및 문제 정의
- 패션, 영화, 개발 등 다양한 분야를 중심으로 하는 커뮤니티 사이트가 있지만 도서 분야에서는 뚜렷하게 대두되는 커뮤니티가 없음
- 도서에 대한 리뷰가 서점 사이트마다 산재되어 있으며 소통 중심의 사이트가 아님
- 도서에 대한 감상을 나누거나 독서가 취미인 사람들과의 소통을 원하는 사람들에게 커뮤니티를 제공하는 것을 목표로 함

### 1.2 목표
- 도서 정보 및 리뷰 공유와 사용자간의 커뮤니티 구축

### 1.3 타겟 사용자
- 도서 전용 커뮤니티를 원하는 사용자
- 도서 리뷰를 작성하고 관리하는 개인 공간을 원하는 사용자
- 다른 사람들의 리뷰를 모아보고 싶은 사용자
- 신간 소식이나 서점별 리커버 소식 등, 도서에 대한 더욱 다양한 정보를 원하는 사용자
- 절판/품절 도서를 중고거래 하고자 하는 사용자

---

## 2. 핵심 기능
- 도서 리뷰 작성
- 도서 거래글 작성 및 거래자간 채팅 기능
- 사용자간 구독으로 커뮤니티 구성

---

## 3. 도메인

| 도메인 | 설명 |
|-----------|------|
| USER | 회원가입/로그인/프로필/구독 |
| BOOK | 외부 API 기반 도서 정보 캐시/조회 |
| REVIEW | 도서 리뷰 |
| POST | 판매글/구매글(거래 게시물) |
| CHAT | 1:1 채팅 |
| COMMUNITY | 사이트 커뮤니티 글 |
| COMMENT | 댓글/대댓글(COMMUNITY, REVIEW 공통) |
| LIKE | 좋아요(BOOK, POST, COMMUNITY, COMMENT, REVIEW 공통) |
| SUBSCRIBE| 사용자 간 구독(팔로우) |

- COMMENT와 LIKE은 타겟 대상의 도메인만 다를 뿐, 그 외 도메인 구조가 동일하기 때문에 도메인간 공통으로 구성
